# Airline Ticket Reservation System

A comprehensive airline reservation system built as a core Java Console Application. It enables passengers to search, book, and manage flight tickets with seamless payment simulation, seat selection, and booking management capabilities.

## Project Scope
- User Registration & Authentication (Role-based: Admin, Passenger, AirlineStaff)
- Flight Search and Discovery
- Seat Selection and Assignment
- Booking Management (Create, Modify, Cancel)
- Payment Processing Simulation
- Notification System Simulation
- Reporting and Analytics

## Technologies Used
- Core Java
- Collections Framework
- Stream APIs
- Object Oriented Programming (OOP) Principles
- Design Patterns (Singleton, State)
- Data Structures (PriorityQueue)
